# Aqua Nuqi — Install guide

One page. Keep this on your phone or print it. No technical knowledge needed.

---

## Download

**Windows (your laptop):**

https://github.com/Muhammad-Nabeel-Asif/aqua-nuqi/releases/latest/download/Aqua-Nuqi-Setup.exe

Open that link in any browser. The file **Aqua-Nuqi-Setup.exe** will download.

---

## Install (first time)

1. Open the downloaded file (double-click it).
2. If Windows shows a blue box saying **"Windows protected your PC"**:
   - Click **More info**
   - Then click **Run anyway**
3. Click through the installer (Next → Next → Install).
4. When it finishes, open **Aqua Nuqi** from the desktop shortcut or the Start menu.
5. On first launch, choose **Set up a new business** and fill in your business name.
   (If you already have a backup from another computer, choose **Restore from a backup** instead.)

You do **not** need an administrator password. The app installs for your Windows user only.

---

## Where your data lives

Your customers, deliveries, bills and money records are **not** inside the installer.

They are saved here on your computer:

`C:\Users\<your-name>\AppData\Roaming\Aqua Nuqi\`

Updating or reinstalling the app does **not** delete this folder.

---

## How to update later

From version 1.0 the app can also offer **Restart to update** by itself (stable
releases only). You can still update manually:

1. Download **Aqua-Nuqi-Setup.exe** again.
2. Double-click it and install **over** the old version.
3. Do **not** uninstall first.
4. Open Aqua Nuqi — your data is still there.

Updating the app never removes your business data.

### Portable USB copy (optional)

https://github.com/Muhammad-Nabeel-Asif/aqua-nuqi/releases/latest/download/Aqua-Nuqi-Portable.exe

Data for the portable build is stored in a folder named **Aqua Nuqi Portable Data**
next to the exe. It is **not** shared with the installed version.

### Uninstall

If you uninstall from Windows Settings → Apps, your business data is kept by default.
You will be asked whether to also delete it — choose **No** unless you have a verified
backup elsewhere.

---

## If something looks wrong

- If the app says **"this version is older than your data"** — stop. Do not continue. Contact the developer and install the newest version from the link above.
- If Windows still blocks the file, use **More info → Run anyway** (step 2 under Install).
- For a new laptop: ask the developer for the backup-and-restore steps before you wipe the old machine.
