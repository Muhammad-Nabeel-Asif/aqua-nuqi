# Client Meeting Questionnaire

A plain-language script for the next meeting. No technical words — walk through it in order and
write the answers in the blank lines. Roughly 30–40 minutes.

**Why each question matters** is noted in italics for you, not for him. Don't read those out.

Already settled, don't re-ask: single plant (no second branch planned), and the owner enters the
daily data himself on one laptop.

## Things to say out loud before you leave

1. **"This runs on one laptop only."** If a clerk later needs their own computer, that's a
   different piece of work with a different price. Get a nod on this.
2. **"Backups are your insurance."** We'll set up automatic backups to the laptop plus a second
   place. If both are lost, the data is gone. Confirm the second place today.
3. **"The first month we run alongside paper."** Not because the app is unreliable, but because
   his opening balances need verifying.
4. **"You'll get working versions along the way."** Delivery tracking and bills first — that alone
   replaces the cards. Expenses, salaries, bottle tracking and profit reports come after.
5. **"WhatsApp sending is two clicks, not automatic."** Fully automatic sending needs a paid
   WhatsApp business account. The free way is: the app opens the chat with the message ready and
   the bill file ready to attach. Show him this early so it isn't a surprise.
